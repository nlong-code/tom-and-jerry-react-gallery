# Tom & Jerry React Image Gallery

This is my React assignment featuring my favorite cartoon, Tom & Jerry.

The gallery includes four pictures featuring Jerry, Tom, and the Tom & Jerry logo. I created a reusable Image component to display the pictures using different image sources and widths.

### Files Included
- App.jsx
- Image.jsx
- app.css
- index.css
- main.jsx
- Images folder

### How to Run the Project
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Type `npm.cmd install`.
4. After installation, type `npm.cmd run dev`.
5. Open the local website address shown in the terminal.
