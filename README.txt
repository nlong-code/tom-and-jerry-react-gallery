TOM & JERRY REACT IMAGE GALLERY

This ZIP contains the complete Vite + React project files:
- index.html
- package.json
- vite.config.js
- src/App.jsx
- src/app.css
- src/index.css
- src/main.jsx
- src/components/Image.jsx
- src/images/jerry.png (image supplied in the conversation)
- src/images/tom-and-jerry-logo.png (image supplied in the conversation)

HOW TO RUN:
1. Extract this ZIP folder.
2. Open the extracted tom-and-jerry-complete folder in Visual Studio Code.
3. Open Terminal > New Terminal.
4. Run: npm.cmd install
5. When installation finishes, run: npm.cmd run dev
6. Open the Local address shown in the terminal (usually http://localhost:5173/).

The Jerry image and logo are saved locally. The Tom image and the Tom-and-Jerry-together
image use online URLs, so those two require an internet connection. If an online URL
stops working, replace it in src/App.jsx with a working image URL or a local image file.
